# Fabric API base bridge

This module independently implements the public binary contract of
`net.fabricmc.fabric-api:fabric-api-base:0.4.42+6573ed8c19`, the version pinned
by Fabric API `0.116.15+1.21.1`. It intentionally advertises only the classes it
actually implements.

Authoritative references:

- https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.116.15%2B1.21.1/
- https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api-base/0.4.42%2B6573ed8c19/
- https://github.com/FabricMC/fabric-api/tree/0.116.15%2B1.21.1/fabric-api-base

The implementation is original LoaderBridge code. Fabric API is Apache-2.0;
attribution and project boundaries are recorded in the repository `NOTICE`.
